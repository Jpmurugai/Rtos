1. Overview

Users belong to projects through a membership table. Each project has tasks; each task can have an assignee and comments.

7. Validation & Business Rules

  • Email must be unique and valid format.
  • Password minimum 8 characters.
  • Task status only: todo, in_progress, done.
  • Assignee must be a member of the project.
  • Deleting a project deletes its tasks and comments (cascade).
