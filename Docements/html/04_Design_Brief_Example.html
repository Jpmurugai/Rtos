1. Design Goals

  • Mood: Clean, calm, professional – focus on the tasks, not decoration.
  • Principles: Simple (max 3 clicks to any action), Consistent (same components everywhere), Clear status (colour + text for each task state).

2. Target Audience

Students and small teams (2–10 people) who need a lightweight alternative to big project tools. Mixed technical skill, use both laptop and phone.

7. Accessibility

  • ☑ Contrast meets WCAG AA (4.5:1 for text)
  • ☑ Full keyboard navigation (Tab / Enter / Esc)
  • ☑ Alt text for all images and icons
  • ☑ Status shown with text, not only colour

  • Jira (status workflow)
